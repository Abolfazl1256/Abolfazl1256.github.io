# Abolfazl personal website — updated

Features: English and Persian pages, RTL Persian layout, light/dark theme toggle, profile-photo support, and printable CV.

## Update GitHub Pages
Extract this ZIP. In your `Abolfazl1256.github.io` repository choose **Add file → Upload files**. Drag the contents of this folder into the repository root and commit. Confirm that `index.html`, `fa.html`, `cv.html`, `styles.css`, `script.js`, and `assets/` are at the root.

## Add your photo
Upload a square JPG photo to `assets/` and name it exactly `profile.jpg`. It will appear in the profile card.

## PDF CV
The previous PDF URL failed because no PDF had been uploaded. The new **View / Print CV** opens `cv.html`. Press **Print / Save as PDF**, then select **Save as PDF** in the browser print dialog.

Before publishing, replace `YOUR-LINKEDIN` and `YOUR-EMAIL@example.com`, verify job descriptions, dates, and degree titles.
