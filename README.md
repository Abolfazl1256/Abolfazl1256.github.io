# Abolfazl — Personal CV Website

A responsive, static English-language portfolio website built with HTML, CSS and vanilla JavaScript. It is ready for GitHub Pages.

## 1. Before publishing: personalize these placeholders

Open `index.html` and replace:

- `Abolfazl` if you want a different display name.
- `YOUR-EMAIL@example.com` with your professional email.
- `YOUR-LINKEDIN` with the public part of your LinkedIn profile URL.
- `YOUR-GITHUB` with your GitHub username.

Also verify the job titles and descriptions, add exact employment dates, and confirm official English degree titles and graduation years. Do not publish confidential employer data.

## 2. Add your PDF CV

Export your final CV as a PDF named exactly `Abolfazl_CV.pdf` and put it in the `assets` folder. The Download CV button already points to this path. If you do not want to publish a PDF yet, remove that button from `index.html`.

## 3. Publish with GitHub Pages

1. Sign in to https://github.com (or create an account).
2. Create a **public** repository named exactly `YOUR-USERNAME.github.io` (replace with your GitHub username).
3. Upload the contents of this folder to the repository root. `index.html` must be at the root, not inside another folder.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then Save.
7. Wait a few minutes and open `https://YOUR-USERNAME.github.io`.

## 4. Optional: connect a custom domain later

You do not need a custom domain to publish. GitHub Pages supports custom domains, but a `.cv` domain is normally registered separately and may have a fee. When you buy one, add it under **Settings → Pages → Custom domain**, then configure the DNS records required by GitHub's current documentation.

Official guide: https://docs.github.com/en/pages

## 5. Local preview

Double-click `index.html` to preview the site in a browser. For best results, use a local development server, but it is not required for this static site.

## Notes

- The site is English-first and designed for international job applications.
- Project summaries are deliberately high-level. Add sanitized screenshots and quantified outcomes only where you have permission.
- The current profile content is based on information previously provided and should be checked for accuracy before going live.
